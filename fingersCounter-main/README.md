# Hand Tracking

Este é um projeto de detecção e contagem de dedos usando OpenCV e Mediapipe.

## 🚀 Tecnologias Usadas:
- Python 3
- OpenCV
- Mediapipe

## 📌 Como Usar
1. Instale as dependências:

pip install opencv-python mediapipe

2. Execute o script:

python hands.py

3. Pressione **'q'** para fechar a janela.
